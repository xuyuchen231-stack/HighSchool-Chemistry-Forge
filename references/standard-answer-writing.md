# 首页参考答案：简洁且得分点完整

在详细教学解析之前，先给可独立使用的参考答案。可使用选择题表格、题号和小问编号，沿用常规考试参考答案格式。称“参考答案”，未经官方来源核实不要标成“官方标准答案”。

对解释、比较、推断、实验理由题，写完整因果链：
**题设结构或事实 → 使用的原理 → 导出的性质或变化 → 回应问题的结论。**
只保留完成得分所需的内容，不把详细教学推导塞进答案区；也不能为了短而删掉关键对象、比较关系、试剂作用或最终结论。

## 本次范例
问题：从结构与性质解释CCl₄为什么能除去ClO₂、Cl₂混合气体中的Cl₂。

参考答案：Cl₂、CCl₄为非极性分子，ClO₂为极性分子；根据相似相溶原理，ClO₂不易溶于CCl₄，而Cl₂易溶于CCl₄，因此可用CCl₄除去混合气体中的Cl₂。

核对四组得分点：三种分子的极性；相似相溶原理；两种气体在CCl₄中的溶解性差异；选择性除Cl₂的结论。仅写“Cl₂与CCl₄均非极性，所以相似相溶”不完整，因为漏ClO₂的对照；不得写ClO₂“完全不溶”，也不把经验原理推广成任何极性溶质都绝对不溶于非极性溶剂。

## 可迁移规范
- 氧化还原理由：写哪种物质失/得电子、价态如何变化、承担什么作用。
- 平衡理由：写条件改变、哪个平衡受到影响、移动方向及目标量怎样改变；有竞争平衡时保留决定结论的竞争过程。
- 实验方案：写取样、试剂、顺序、现象、结论；删除任意一步会产生假阳性时不能省略。
- 计算：给最终表达式、必要单位与条件；过程放入详解，不能漏分样倍数或体积单位。
- 流程分离：写目标离子、必须保留的离子、阈值交集或相应平衡，不能只写“调节pH”。

交付前逐问核对：首页答案能否单独回答原问？有无仅说一个物质却省去比较对象？是否包含为何能实现目的？详解和答案区是否同一结论？用户提供的参考答案可指导表述，但科学结论仍须核验。
