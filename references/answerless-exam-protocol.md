# 无答案试卷：独立解题与学生易读解析协议

## 0. 输入与完整性
- 接受 PDF、图片、Word、纯文本；扫描件逐页检查图表、结构式、实验装置、坐标、脚注、选项与空格。
- 建立 page/question/subquestion/option 对应关系；题干不能辨认时标记 `needs_visual_review`，不得猜题或补造条件。
- 保留原题单位、条件、限定词（正确/不正确）、化学式上下标、图示箭头与图例。

## 1. 无答案优先
- 先独立求解，不搜索现成答案、不依赖选项暗示反推结论。
- 选择题逐选项判断，非选择题逐空逐问求解；给出每个结论的依据。
- 对复杂题使用至少两种独立检查：守恒/量纲/极限、代入回算、反例、图表一致性等。
- 原题本身若存在歧义，明确列出不同解释与所需补充条件；不承诺百分百正确。

## 2. 学生易读输出（逐问作答，按题组织知识）
默认读者有少量化学基础，先读`student-readable-explanations.md`。每个选项或小问必须有直接、能读懂的理由；整题共用的知识精讲、变式、延伸集中写，不在每个选项下重复。科学核查过程按需保存在审校记录中，正文只展示帮助学生理解的步骤。
1. 原题定位：页码、题号、小问、考查目标。
2. 答案：简洁且可单独核对，附置信度/待核查点（仅当有意义）。
3. 完整推理：先用学生能懂的话说本问在比较什么，再依据题目条件一步步解释；需要用反应式或公式时，说明每个量、系数和代入步骤。不能只给术语或用“显然”“故易知”跳过关键一步。
4. 知识点：定义、微观解释、成立条件、适用边界、前置概念。
5. 拓展：与本题紧密相关的迁移知识、同类变式；清晰标记超纲内容。
6. 错因：典型误判、常见混淆、反例。
7. 教学：适合板书的步骤、可视化建议、检验理解的小题及答案。
- 多小问不得合并跳过；多选项不得只解释正确项。

## 3. 专题规则
- 晶胞：识别晶格贡献与化学式单元，逐个计数，核查长度单位与密度量纲。
- 氧化还原：氧化数、电子转移、原子/电荷守恒，酸碱介质与副反应。
- 平衡/速率：初始-变化-平衡表、温压条件、K表达式、图轴定义。
- 实验：试剂作用、装置顺序、现象、干扰因素、对照和安全性。
- 工业流程：物料流、价态变化、沉淀pH窗口、产率与选择性。
- 结构：轨道/价层电子对/配位/共轭分别解释，不混用术语。

## 4. 审核与交付
- 生成逐题检查表：题号、小问、所有选项、知识点、图表读取状态、守恒复核状态、疑点。
- 任一图像未确认、推导有矛盾、守恒不通过时标为待复核，不可宣称通过。
- 先交独立答案总表，再交逐题详解和知识点总索引；篇幅过长时分卷但必须覆盖全部题目。
- 交付可追溯的解答版本、源文件及验收记录；如需 PDF/PPT，遵守对应生成和视觉验收规范。
