# Exam analysis protocol

1. Transcribe the full stem, options, diagrams, values and units; do not silently infer missing images.
2. Solve independently before consulting an answer key.
3. For each option: verdict, chemistry reasoning, assumptions, and why alternatives fail.
4. Explain prerequisite ideas (e.g., nuclide notation, electron filling, coordination, charge balance) with a textbook-quality diagram if appropriate.
5. Check numerical calculations, significant figures, reaction balancing, experimental feasibility and terminology.
6. Mark uncertain/ambiguous questions clearly; do not force a single answer when the prompt is insufficient.
7. Produce a concise student solution plus a detailed teacher script and two extension questions when requested.
