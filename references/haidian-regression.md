# 海淀2026—2027高三期中回归案例

原卷SHA-256：34edb13209124c91062aeca6b1b381f37beffbb40ca6de67e635831fd1db956e。8页，14道选择、5道综合，100分，90分钟，无官方答案。答案为独立解答，不标注为官方标准。

必须能识别的失败模式：
- Q8：题干是醋酸，不能拆成H+。
- Q11：不能把移除H+有利配位外推为pH越高越好；Cu(OH)2竞争。
- Q13：NO得3e，NH4+供2e，外部净供1e。
- Q14：用KNO3排除盐效应；氧化显色时SCN浓度差会混淆；HCO3过量需写完整净反应。
- Q15：MnO2晶胞Z=2、配位6；密度体积a²c×10^-21 cm³；返滴定与EDTA各测半份，不能漏倍数。
- Q16：ClO-+ClO2-→Cl-+ClO3-系数1:1；水解常数不能当作速率常数。
- Q17：CO产率为空心方块；0.1→0.2原料转化率基本不变，须推断C+H2O→CO+H2；0.2→0.8另讨论CH4重整。
- Q18(4)：问沉铝，区间4.7≤pH<6.3；Q18(5)沉铁补碱4mol/mol ClO-。不得把两个步骤混读。
- Q19：先除酸雾、再除SO2，判断SO4来源；热分解Na2S2O6→Na2SO4+SO2；(7)为“同意可能来自SO2”。过量BaCl2与Na2CO3的分离链不可跳过，Ba除尽不等于SO3除尽。

最后一点使用NIST/IUPAC Sulfites资料p247核验：BaSO3(s)+CO3²-⇌BaCO3(s)+SO3²-，25℃比值约0.243。网址：https://srdata.nist.gov/solubility/IUPAC/SDS-26/SDS-26-pages_240.pdf 。数值仅用于解释该案例的竞争分离，不要求所有高中题引用此常数。
