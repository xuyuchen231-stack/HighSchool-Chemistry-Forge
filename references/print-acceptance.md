# 教辅PDF排版与验收

保留原卷完整页面于最前，禁止用OCR重排替代。逐页比较渲染与尺寸；不要依PDF对象编号判断内容是否相同。原卷后依次安排答案速查、题解、知识索引、核验资料。以A4正文、深蓝分层标题、红色答案、清楚段距和连续页脚延续解析版教辅层级。

正文通常10.5—12pt、行距约1.5—1.7倍；边距约15—20mm。数学与化学的上下标使用真实排版，不把Unicode字符能输入等同字体能显示。负号、箭头、希腊字母、配离子括号要查字形与文字提取；必要时替换为兼容字体或等价的清晰排版。

优先用矢量图解释装置、结构或平衡。洗气瓶须画长进短出，晶胞图须正确显示图例及共享方式，示意图不伪装测量数据。不要用与化学内容无关的装饰图凑版面。

执行两类检查：
- 自动：页数、书签、题号覆盖、公式字符、异常空白、边界溢出、字体嵌入、原卷页面比对。
- 逐页人工或代理视觉：看每页渲染，确认无叠字、截断、错位上下标、孤立标题、难读图表。记录页码、检查项、发现问题与修复后复查。

完整19题考试通常至少20页实质性解析。37—51页可作为本案例参考，但不得用重复文字或不合理空白追页数。章节按教学单元分页；短章节不强制一页。所有修订后必须重新检查改变的页面及受分页影响的后续页。
