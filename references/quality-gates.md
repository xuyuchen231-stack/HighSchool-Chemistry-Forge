# Acceptance gates

- Coverage: every requested topic/question included, no invented textbook chapter references.
- Chemistry: atom and charge conservation, valence/oxidation states, units, conditions, and exceptions checked.
- Pedagogy: concepts explained causally, not only definitions; examples and misconception corrections are specific.
- Figures: geometry, labels, arrows, crystal boundaries and apparatus scientifically defensible.
- Evidence: traceable sources for nontrivial claims; copyright/license respected.
- Output: deliverable opens, text readable, no clipped formulas/tables, figures referenced correctly.

Fail any gate => revise or explicitly report incomplete; never mark unfinished material as final.

- 学生可读性：默认有少量化学基础。逐项解释用具体物质、条件和分步原因，必要新术语先解释；学生不读深层延伸也能理解判断。按student-readable-explanations.md验收。
