# Teaching artifact specification

PPT: one instructional objective per slide; use readable equation typography and authentic chemistry representations. Prefer editable plots and shapes over rasterized text. Include an answer/explanation slide after exercises.

Handout: title, scope, prerequisite map, definitions, equations with conditions, worked examples, misconceptions, self-check, solutions, references.

Diagram sources: cite external visuals; use chemically validated structures and labels. For crystal cell counting, explicitly show corner/edge/face/body contributions and boundary sharing. For orbitals distinguish probability density from classical trajectories.

For all exported files: render/compile, inspect layout, check missing glyphs, overflow, image resolution and equations. Only state these checks passed if actually performed.
